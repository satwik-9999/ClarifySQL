\# ClarifySQL



AI-powered natural language data assistant that converts English questions into secure SQL queries and interactive insights.



\## 🚀 Features



\- 🧠 Natural language to SQL

\- 💬 Ambiguity detection and clarification

\- 🗄️ Dynamic database schema awareness

\- 🔐 SQL safety and validation

\- 📊 Automatic result visualization

\- 📜 Persistent query history

\- 💬 Session-based conversation context

\- ⚡ FastAPI backend

\- 🎨 Streamlit interface

\- 🎯 Demo Mode
